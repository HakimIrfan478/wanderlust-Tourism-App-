# Wanderlust Tourism Application

Wanderlust is a final-year project developed using React Native, Expo, Python, Django and Django REST Framework.

## Main Features

- User registration and JWT authentication
- Destination discovery and keyword search
- Category filtering
- Personalised destination recommendations
- TF-IDF fallback using scikit-learn
- Favourites and user reviews
- Weather and country information

## Project Structure

- `wanderlust/frontend` – React Native mobile application
- `wanderlust/backend` – Django REST API and recommendation system
